# ICSEPy
A GitHub repo storing my Python and other files related to my Python Project.
## Files
`balaji.json` used for Q11 of the project, where I needed to make a JSON with the daily screen time, app used, and subscription status for 20 users.

`best-selling-books export 2026-05-29 06-17-11.csv` is a dataset downloaded from Kaggle for Q14, where I needed this dataset to plot bar graphs to show the number of books that are sold per year.

`top_200_youtubers.csv` is another dataset from Kaggle, however, it has been modified to not have one of the categories as it had (in my opinion) values that didn't make sense.
